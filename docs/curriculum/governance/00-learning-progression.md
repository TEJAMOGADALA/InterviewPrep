# Purpose

This document defines how learners progress through the PrepOS Knowledge Graph.

It specifies the universal rules governing:

- Topic unlocking
- Adaptive recommendations
- Difficulty progression
- Revision scheduling
- Company prioritization
- Mission generation
- Readiness estimation

No component inside PrepOS may violate the rules defined in this document.

This document acts as the bridge between the Curriculum and the Adaptive Learning Engine.

# Core Progression Principles

Every learner follows a unique path.

However, every path must obey the same learning rules.

These rules are mandatory.

---

# Principle 1 — Foundations First

Every learner begins with Foundations unless sufficient evidence proves they already possess that knowledge.

Foundations may only be skipped when:

- onboarding assessment exceeds the configured threshold
- confidence remains consistently high
- mastery is demonstrated
- prerequisite validation passes

Experience alone must never skip Foundations.

---

# Principle 2 — Prerequisites Are Mandatory

No topic may unlock before all mandatory prerequisites are complete.

Company preference

Interview urgency

Weakness

Mission continuity

must never bypass prerequisite correctness.

Example

Software Architecture

↓

Client Server

↓

Scalability

↓

Caching

↓

Distributed Systems

↓

CAP Theorem

CAP Theorem must never appear first.

---

# Principle 3 — Subject Independence

Every subject progresses independently.

Example

High Java score

does not imply

High DSA score.

Likewise,

Strong DSA

does not unlock HLD.

Each subject maintains its own progression.

---

# Principle 4 — Adaptive Personalization

The adaptive engine considers:

Experience

Assessment

Confidence

Mastery

Weakness

Practice History

Interview Timeline

Target Companies

Mission History

Study Capacity

Revision Queue

Company Importance

Coding Performance

AI Mentor Feedback

No single factor should dominate recommendations.

---

# Principle 5 — Continuity

Learning should feel continuous.

When possible:

Continue the same subject

↓

Continue the same module

↓

Continue the same concept family

↓

Introduce adjacent topics

Avoid unnecessary subject switching.

---

# Principle 6 — Weakness First

Weak subjects should generally receive higher priority.

However,

Weakness must never violate prerequisite ordering.

---

# Principle 7 — Revision Before Forgetting

Completed topics should reappear according to spaced repetition.

Revision should depend upon:

Time since completion

Confidence

Mastery

Difficulty

Interview importance

Previous mistakes

Revision should reinforce learning rather than interrupt it.

# Topic Unlock Rules

A topic becomes unlocked only when:

✓ Mandatory prerequisites completed

✓ Previous learning stage satisfied

✓ Difficulty progression respected

✓ Subject progression valid

Optional recommendations may still appear in previews.
