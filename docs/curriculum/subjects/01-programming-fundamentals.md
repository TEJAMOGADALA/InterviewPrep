# Programming Fundamentals

---

# Vision

Programming Fundamentals is the foundation upon which every technical discipline in PrepOS is built.

The objective of this curriculum is not simply to teach syntax, but to develop computational thinking, algorithmic reasoning, debugging skills, software engineering discipline, and the ability to understand how computers execute programs.

Every learner, regardless of prior experience, must master this curriculum before progressing into language-specific or system-level subjects.

---

# Subject Philosophy

Programming is much more than writing code.

PrepOS teaches programming as a structured engineering discipline where learners first understand:

- How computers execute instructions
- How problems are analyzed
- Why algorithms work
- How memory behaves
- How software is organized
- How engineers reason about correctness
- How maintainable software is built

Instead of memorizing syntax, learners gradually develop engineering intuition that transfers across every programming language.

---

# Learning Objectives

After completing this curriculum, learners should be able to:

- Think computationally
- Break complex problems into smaller components
- Read and write structured programs
- Understand program execution
- Debug efficiently
- Analyze correctness
- Estimate algorithm complexity
- Understand memory behaviour
- Write maintainable code
- Transition confidently into Java and Data Structures
- Apply engineering best practices from the beginning
